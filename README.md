# Portal de Avances · WeSoft

Landing de la iniciativa: un portal donde cada cliente ve las fases, el tablero, las reuniones y el avance de su proyecto,
con un cerebro que arma los documentos del negocio y un agente que dimensiona cada mejora antes de cotizarla.

- Sitio: https://raulgm00.github.io/portal-avances/

## Editar la landing
Se edita `_fuente.html` y se arma `index.html` con el kit `landing-fx` del skill web-premium:

```
py D:/skills/web-premium/scripts/armar-landing.py _fuente.html index.html
```

Después se audita con `node D:/skills/web-premium/scripts/auditar-premium.mjs index.html _auditoria`.
